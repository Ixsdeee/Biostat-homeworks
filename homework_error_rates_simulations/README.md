# Ошибки I и II рода

## Как выполнить и сдать

1. Откройте папку задания в Positron (`File → Open Folder`). Данные генерируются в коде. Отдельный файл с данными не нужен.
2. Заполните `homework_error_rates_simulations.qmd` кодом и текстовыми ответами, сохраняя структуру задания.
3. Отрендерите заполненный файл в html кнопкой Preview в Positron или командой `quarto render homework_error_rates_simulations.qmd`.
4. Перед сдачей убедитесь, что qmd выполняется целиком без ошибок и без объектов, созданных вручную вне отчёта. html должен соответствовать последней версии сдаваемого qmd и содержать все графики и ответы.
5. Создайте папку `homework_error_rates_simulations` в своём приватном репозитории GitHub и загрузите в неё qmd и html. Рекомендуем использовать уже созданный репозиторий с домашними заданиями курса.
6. Пригласите в репозиторий **GitHub-аккаунт проверки**: [bicheck2013](https://github.com/bicheck2013), если этого ещё не сделали.
7. Чтобы сдать задание, **приложите ссылку на папку `homework_error_rates_simulations` в вашем репозитории GitHub**. По ссылке должны быть доступны оба файла отчёта.
