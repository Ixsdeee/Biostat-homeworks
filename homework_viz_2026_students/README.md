# Визуализация биомедицинских данных

## Как выполнить и сдать

В домашнем задании вы продолжите работать с данными `hogwarts`. Этот файл лежит в папке задания вместе с данными (`data`) и картинками к заданиям (`images`). Решения пишите в `homework_viz_2026.qmd`: под каждым заданием оставлен пустой чанк.

1.  Откройте папку задания в Positron (`File → Open Folder`). Проект — это и есть открытая папка, R работает из её корня.
2.  Файл задания лежит в корне этой папки, рядом с `data` и `images`.
3.  Все пути — относительные, от корня проекта: `data/hogwarts_2026.csv`, `images/task_2_4.png`. Путей вида `C:/Users/…` в работе быть не должно.
4.  Отрендерите файл в HTML: кнопкой Preview в Positron или в терминале командой `quarto render homework_viz_2026.qmd`. Рядом появится `homework_viz_2026.html`.
5.  Загрузите `.qmd` и `.html` на свой GitHub, в папку `basic_datavis_hw_2026`.
6.  Чтобы сдать задание, **приложите ссылку на закрытый репозиторий GitHub** *(Лучше будет создать репозиторий для всех будущих домашек и приложить ссылку на подпапку с этим заданием)*
